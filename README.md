# GBUS-652-Coursework
A repository for the weekly coursework for GBUS 652 (Foundations of AI and LLMs)

## About

This repository contains course materials and coursework for UMW's GBUS 652: AI & LLM Foundations. Content is organized by week, with each week's materials stored in its own folder.

## Weekly Work

1. [week-01](week-01/): Tic-Tac-Toe browser game ([play online](https://michaelsmithpe-ops.github.io/GBUS-652-Coursework/week-01/Tic-Tac-Toe.html))
2. [week-02](week-02/): Prompt Lab web app for testing prompts against Claude, built with Claude Code ([try it online](https://michaelsmithpe-ops.github.io/GBUS-652-Coursework/week-02/prompt-lab.html))

   [![Run Prompt Lab](https://img.shields.io/badge/%E2%96%B6%20Run-Prompt%20Lab-c15f3c?style=for-the-badge&logo=claude&logoColor=white)](https://michaelsmithpe-ops.github.io/GBUS-652-Coursework/week-02/prompt-lab.html)

3. [week-03](week-03/): RAG tool that answers questions from Copperline Manufacturing's finance documents, built with Claude Code
4. [week-04](week-04/): AI agent that prepares replies to HR emails using tools from an MCP server, built with Claude Code. Works for any organization's policies, employee file and inbox; first built for Hartwell Foods, then pointed at Ridgeline Hotels ([seven saved runs](week-04/runs/) and [write-up](week-04/writeup.md))
5. [week-05](week-05/): A team of AI agents that prepares a manufacturer's response to supplier emails, run under two coordinators (a fixed pipeline and an orchestrator agent), built with Claude Code. Works for any company's parts, orders, suppliers and inbox; first built for Brookfield Bicycle, then pointed at Copperline Coffee Machines
6. [capstone](capstone/): Capstone project, the Fort GBUS Counter-Drone Decision Aid. A team of AI agents (analyst, reviewer, safety agent) recommends the least force that works against a drone near a fictional base, using tools from an MCP server and a search of the base's rules, while a human operator and control room make every decision on a web page. Built with Claude Code ([project page](capstone/README.md) and [write-up](capstone/writeup.md))
